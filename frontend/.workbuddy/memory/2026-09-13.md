## 一、修复：切换 page 后数据丢失（核心 bug）

**现象**：在 page A 上编辑后切到 page B，A 的改动消失。

**根因**：`BookWorkspaceView.vue` 里的 `scheduleSave` 是 800ms 防抖。用户在防抖窗口内切页时：
1. `selectPage(B)` 立即把 `currentPageId` 改成 B 并 `loadCanvas(B)`，`canvas.value` 被整体替换；
2. 随后旧的定时器才触发 `saveCanvas()`，此时它读到的 `currentPageId` 和 `canvas.value` **都已经是 B 的**，
   于是把 B 的数据又写回 B，A 的改动永远丢掉了。

**修复**（`src/stores/workspaceStore.ts`）——把保存改成「快照队列 + 切换前强制落盘」：

```ts
interface SaveJob { pageId: number; data: CanvasResponse; at: number }
let saveQueue: SaveJob[] = []
let saveTimer: number | undefined

function snapshot(src) { return JSON.parse(JSON.stringify(src)) }

/** 入队时就深拷贝快照，并记住当时的 pageId */
function stashCurrent() { … saveQueue.push({ pageId, data: snapshot(canvas.value) }) }

function scheduleSave(delay = 800) { stashCurrent(); /* 重置定时器 */ }
async function flushSave() { /* 清定时器 → 依次 PUT 各 job → 失败则放回队首 */ }
async function safeFlush() { try { await flushSave() } catch { /* 留队重试，不阻塞导航 */ } }
function dropPendingSave(pageId) { /* page 被删除时丢弃其待保存作业 */ }
```

关键点：
- **快照在入队时做**，所以即使用户随后切页，旧页的数据依然写回旧页。
- `selectPage` / `selectEvent` 开头 `await safeFlush()`，**先落盘再换画布**。
- `removePage` 先 `dropPendingSave(id)`，避免 PUT 打到已删除的 page。
- 失败不静默吞掉：作业放回队首，`saveState = 'error'`。
- `clearWorkspace` 清空队列与定时器。

视图层 `scheduleSave()` 简化为直接调 `workspaceStore.scheduleSave()`，不再自己管定时器。

# 第三轮修复（2026-09-13 下午）

## 1. 注解「打字即清空」根因（重要教训）
`CanvasAnnotation` 的标题输入框原来写 `:value="title"`（computed 自 props）。
**任何**响应式状态变化（如 `hovering`）触发重渲染时，Vue 会把 DOM value 拍回旧 props 值 →
用户正在打的字被抹掉。修复：标题改为本地 `titleDraft` ref（v-model），
watch content 时只在输入框未聚焦时回填。
**规则：受控输入绑定 computed(props) 且组件有高频变化的本地状态时，必须用本地 draft。**

## 2. 画布无法平移的根因（重要教训）
`.node-layer` SVG（1600×1400）没有 `pointer-events: none`，盖满画布吃掉所有 mousedown，
`onCanvasMouseDown` 只认 `.canvas-area`/`.grid-layer`，几乎永远不触发。
修复：node-layer 加 `pointer-events: none`，CanvasNode 的 `.node` 加 `pointer-events: auto`。
新增 `moveMode`：点工具条箭头图标切换，mode-move 抓手光标，Esc/点其他工具退出。

## 3. 关系线箭头不显示
放弃 SVG `<marker>`（渲染不可靠且难排查），改为 CanvasRelation 内几何计算显式画 polygon 三角箭头：
线身端点 = 中心连线与对象外接矩形的交点，箭头 tip 贴轮廓。
标签去 rect 方框，沿法线偏移 11px + 白描边光晕（paint-order: stroke），随线角度倾斜（限 ±34°）。
**遗留**：同对象对建第二条关系被覆盖——疑似后端按 (source,target) 去重，已写入后端需求文档。

## 4. 关系图抽屉重做
去掉「来源」下拉；改为 列表层（listRelationGraphs + 新增按钮）→ 详情层（getRelationGraph）。
新增 = createRelationGraph 建壳 → extractRelationGraph 提取（失败回退当前画布推导）→ saveRelationGraphData。
详情层可删关系/删对象/加关系（两个 select + label + 线型），每次变更整体 PUT data，不动画布。

## 5. 新增交互
- 时间线右缘/下缘拖拽手柄调大小：横向存 `Timeline.width`（320-1440），纵向存 `height`（260-1400），拖动中实时 measure()。
- 侧栏 event/page 列间 `.col-resize` 拖柄：eventColW 130-300px，localStorage key `wb.colW.event`。
- 类型新增：`Timeline.width?` / `Timeline.height?`；store 新增 `setTimelineSize(id, {width?, height?})`。

## 6. 流程坑（再次踩到）
**对同一文件并行发多个 Edit 时只有最后一个生效**——本轮 setTimelineSize 函数体和 @resize 绑定两次被吞。
教训：同一文件的多处修改必须串行 Edit，或合并成一次 Edit。

vue-tsc --noEmit → EXIT=0；vite build → ✓ built in 1m12s。
后端接口需求更新：docs/后端接口需求.md（Timeline 四字段 + 关系不去重 + 原有三项 + curl 脚本 + 给后端的 prompt）。

- gap 以**中位数** med 归一，权重 `w = 0.75 + min(4, log2(1 + gap/med))`。

- 权重归一铺满可用长度（首尾 42px 呼吸），再抬到最小可读间距 `minLabelPx*0.8`，超出则整体等比压回。
- 输出 `row`/`tickRow`（相邻过近自动上下错行）+ `hasSpan`/`endPos`（时间段）。
- ⚠️ **踩坑**：`bps.sort((a,b) => a.ts - b.ts || (a.isEnd ? 1 : -1))` 比较器不自洽
  （两者同类时也返回 -1），稳定排序会把同刻的点排反 → 位置递减。
  必须写成 `a.isEnd === b.isEnd ? 0 : a.isEnd ? 1 : -1`。
- `TimelinePanel.vue`：时间段用**马克笔涂抹**（两段 Q 曲线 + 圆头 + 底层晕染 `mk-bleed`）；

## 1. **族谱「三代之后接不下去」的真因（重要教训）**
代数原来按**个人**松弛：`gen[to] = max(gen[to], gen[from]+1)`。
配偶若是**外来者**（自己父母没录进族谱），它没有任何亲子边 → 个人代数永远停在 0，
于是「外来配偶 + 血亲」所生的子女只拿到 1 → **被排到上面几行、连线向上折返**。
用户看到的「第三代之后接不下去」就是这个。
**修复**：`layoutFamilyTree` 改成按**配偶单元**松弛代数 —— 先并查集建单元，
再在单元粒度上迭代 `unitGen[childUnit] = max(…, unitGen[parentUnit]+1)`，
同单元内成员共享代数（`up === uc` 时跳过，防自增死循环）。
用例验证：外来配偶链 4 代 → `generations=4`，庚从 gen1 纠正到 gen3，连线 `y 254 → 316` 向下。
