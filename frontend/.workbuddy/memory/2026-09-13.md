## 一、修复：切换 page 后数据丢失（核心 bug）

**现象**：在 page A 上编辑后切到 page B，A 的改动消失。

**根因**：`BookWorkspaceView.vue` 里的 `scheduleSave` 是 800ms 防抖。用户在防抖窗口内切页时：
1. `selectPage(B)` 立即把 `currentPageId` 改成 B 并 `loadCanvas(B)`，`canvas.value` 被整体替换；
2. 随后旧的定时器才触发 `saveCanvas()`，此时它读到的 `currentPageId` 和 `canvas.value` **都已经是 B 的**，
   于是把 B 的数据又写回 B，A 的改动永远丢掉了。

**修复**（`src/stores/workspaceStore.ts`）——把保存改成「快照队列 + 切换前强制落盘」：

```ts
interface SaveJob { pageId: number; data: CanvasResponse; at: number }
let saveQueue: SaveJob[] = []
let saveTimer: number | undefined

function snapshot(src) { return JSON.parse(JSON.stringify(src)) }

/** 入队时就深拷贝快照，并记住当时的 pageId */
function stashCurrent() { … saveQueue.push({ pageId, data: snapshot(canvas.value) }) }

function scheduleSave(delay = 800) { stashCurrent(); /* 重置定时器 */ }
async function flushSave() { /* 清定时器 → 依次 PUT 各 job → 失败则放回队首 */ }
async function safeFlush() { try { await flushSave() } catch { /* 留队重试，不阻塞导航 */ } }
function dropPendingSave(pageId) { /* page 被删除时丢弃其待保存作业 */ }
```

关键点：
- **快照在入队时做**，所以即使用户随后切页，旧页的数据依然写回旧页。
- `selectPage` / `selectEvent` 开头 `await safeFlush()`，**先落盘再换画布**。
- `removePage` 先 `dropPendingSave(id)`，避免 PUT 打到已删除的 page。
- 失败不静默吞掉：作业放回队首，`saveState = 'error'`。
- `clearWorkspace` 清空队列与定时器。

视图层 `scheduleSave()` 简化为直接调 `workspaceStore.scheduleSave()`，不再自己管定时器。

- `CanvasNode.vue` 副标题改为读 `customFields`：人物显示 `职业 · 35 岁`，事件显示时间，事物显示类别。

## 四、关系连线

- 工具条「关系」改为**一个图标**，点击弹出三种线型（单向箭头 / 双向箭头 / 虚线箭头），**选完自动收起**。
- 交互链路：选线型 → 悬停对象轻微放大（`transform-box: fill-box` + `scale(1.06)`）→
  点第一个锁定为起点（实心描边 + 放大）→ 悬停其它对象放大 + 画虚线预览 → 点第二个 → **弹窗命名**。
- 新增 `relDialog`：命名 + 改线型 + 删除关系（双击关系标签可再次打开）。
- 画布顶部新增 `link-hint` 提示条（显示当前线型与下一步操作 + 「退出」按钮）。
- `CanvasRelation.vue`：**虚线现在也带箭头**（原来 `hasEndArrow = type !== 'dashed'` 是错的）；
  标签改为**把线身从中间断开一个标签宽度**，标签嵌在缝里，真正「贴合在线边上」。

## 五、注解真富文本

- 从 `contenteditable="plaintext-only"` 改为**完整 contenteditable**，内容按 HTML 存 `Annotation.content`。
- 能力：加粗 / 斜体 / 下划线 / 删除线 / 字号(12·14·16·20) / 字色(8 色) / 背景色(8 色) / 清除格式。
- 加粗等用 `document.execCommand`；**字号/字色/背景色用手写 `applyStyle`** 给选区套一层带内联样式的 `<span>`，
  生成的 HTML 干净可往返（`surroundContents` 失败时回退到 `extractContents` + 包裹）。
- **UI 收敛为单图标**：工具栏默认隐藏，悬停注解才显示右上角铅笔图标，点击才带出具体格式工具。
- 内容结构：标题以 `<h4 class="anno-h">` 存在 `content` 开头，正文其后 —— 只依赖 `content` 一个字段即可完整往返；
  兼容旧数据（首行 `［批注］xxx` 会在解析时迁移）。
- 拖动只从左侧握把发起，正文区域留给文本选择（原来整块 `mousedown.stop` 导致选不中文字）。
- 标题清空用 DOM 直读（`titleEl.value?.value`），避免为空时回退到旧标题。
